# Aurix Input Website

Static multi-page frontend for a premium keyboards and mouse website.

## Pages

- `index.html` - homepage with hero, featured products, category cards, story section, and newsletter
- `products.html` - responsive product listing with category and sorting filters
- `product.html` - reusable product detail page powered by the shared catalog data

## Files

- `assets/css/styles.css` - full visual system, layout, responsive behavior, and motion
- `assets/js/products.js` - shared product data
- `assets/js/main.js` - homepage rendering, animations, and mobile navigation
- `assets/js/listing.js` - product grid filters and sorting
- `assets/js/detail.js` - product detail rendering

## Customizing products

Edit `assets/js/products.js` to:

- add or remove products
- change pricing and descriptions
- update categories and specs
- control which products appear as featured
